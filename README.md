# MutationBenchmark

**Автоматизированный исследовательский бенчмарк для сравнительного анализа инструментов мутационного тестирования Java-приложений.**

Данный проект разработан в рамках научно-исследовательской работы (НИР) для профилирования и оценки производительности фреймворков **Major** и **PITest**. Проект предоставляет автоматизированный пайплайн для сбора системных метрик, агрегации данных и проведения статистического анализа.

## 🎯 Аннотация
Интеграция мутационного тестирования в CI/CD процессы сопряжена с высокими вычислительными затратами. Цель данного бенчмарка — изолированное тестирование Java-модулей с профилированием времени выполнения и пикового потребления ОЗУ. Архитектура позволяет проводить многократные итерации (по умолчанию N=30) для нивелирования влияния JIT-компилятора и Garbage Collector, обеспечивая статистическую достоверность результатов (Mann-Whitney U Test).

## ✨ Ключевые возможности
* **Изолированный запуск:** Автоматическая инъекция тестируемых модулей в структуру Maven-проекта.
* **Сбор системных метрик:** Мониторинг времени выполнения и пикового потребления памяти (RAM) с помощью psutil.
* **Встроенная аналитика:** Автоматическая генерация графиков (Boxplot, Barplot) с использованием seaborn и matplotlib.
* **Статистическая оценка:** Расчет p-value по критерию Манна-Уитни для оценки значимости временных различий между фреймворками.
* **Генерация отчетов:** Автоматическое формирование сводного Markdown-отчета (FINAL_REPORT.md) и CSV-таблиц.

## ⚙️ Системные требования

**Важно:** Нативная поддержка Windows не предусмотрена из-за архитектурных ограничений интеграции плагина Ant для компилятора Major. Пайплайн спроектирован для Unix-подобных систем.

* **ОС:** Linux / macOS / WSL2 (Windows Subsystem for Linux)
* **Языки и платформы:**
    * Java 8+ (Тестируемые модули должны соответствовать правилам JUnit 4)
    * Apache Maven 3.6+
    * Python 3.8+

## 🚀 Быстрый старт (Установка и запуск)

Проект включает bash-скрипт для автоматического развертывания виртуального окружения и установки всех необходимых Python-библиотек (pandas, scipy, seaborn и др.).

1. **Склонируйте репозиторий и перейдите в папку проекта:**

   `git clone https://github.com/mdesmondo/MutationBenchmark.git`

   `cd MutationBenchmark`

2. **Настройка окружения Java (Критически важно):**

   Для корректной работы компилятора и Maven необходимо установить JDK 11 и настроить системные переменные.

   `export JAVA_HOME=/путь/к/вашему/jdk-11`

   `export MAJOR_HOME=/путь/к/распакованной/папке/major`

   `export PATH=$JAVA_HOME/bin:$PATH`

   *(Рекомендуется добавить эти команды в ~/.bashrc или ~/.zshrc).*

2. **Настройте виртуальное окружение (один раз):**

   `chmod +x setup.sh`

   `./setup.sh`

3. **Запустите бенчмарк:**
   Укажите путь к директории с Java-модулями и задайте количество итераций (рекомендуется 30 для статистической значимости).

   `./venv/bin/python3 run_benchmark.py --path ./src/main/java/modules --iterations 30`

   *Запуск с файлами-помощниками (например, для набора QuixBugs):*
   Если тестируемым модулям для компиляции требуются внешние зависимости (общие классы, интерфейсы), передайте путь к ним через флаг `--helper`. Скрипт автоматически подтянет все `.java` файлы из указанной директории.

   `./venv/bin/python3 run_benchmark.py --path ./modules --iterations 30 --helper ./common_helper`
## 📁 Структура проекта
* `run_benchmark.py` — Ядро пайплайна: оркестрация Maven, сбор метрик, генерация отчетов и графиков.
* `setup.sh` — Скрипт конфигурации изолированной среды выполнения.
* `pom.xml` — Конфигурация Maven с настроенными плагинами Major и PITest.
* `major-analysis.xml` — Конфигурация мутационных операторов для фреймворка Major.
* `analytics/` — Директория, генерируемая автоматически после каждого запуска. Содержит все артефакты (логи, графики, CSV, стат. анализ).
* `docs/` - Директория, в которой генерируеются отчеты Major и PITest при индивидуальном запуске.

## 📊 Формат выходных данных
После завершения работы скрипта в папке `analytics/run_YYYY-MM-DD_HH-MM-SS/` будут созданы следующие артефакты:
1. `FINAL_REPORT.md` — Сводный отчет с таблицей результатов и списками выживших мутантов.
2. `raw_metrics.csv` и `nir_data.csv` — Сырые данные мониторинга для дальнейшей обработки.
3. `*.png` — Графики распределения времени (Boxplot), ОЗУ, а также Mutation Score (Barplot).
4. `stat_analysis.txt` — Результаты проверки статистической значимости (Mann-Whitney U Test).
